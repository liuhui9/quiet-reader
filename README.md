# 留白 · 悬停小说阅读器

Windows / macOS 共用 Electron 源码。以小型透明阅读窗为主，书籍保存在本地，不含在线书源。

## 界面与交互

设置采用蓝紫与冷灰配色，分为阅读外观、窗口行为、快捷键三个分类。阅读外观提供晴日、雾蓝、夜航三组配色，并用右侧预览即时展示字号、文字颜色与背景透明度。更改需点击底部“保存更改”持久保存。窄窗口自动收起预览。

## 使用

- 首次打开会显示设置页；后续启动恢复原窗口位置。托盘蓝色书页图标可打开设置，重复运行程序也会打开设置。
- 在设置中点击“找回阅读窗口”，阅读区会移动到鼠标附近，然后设置页收起。
- 鼠标进入阅读区显示，移出即隐藏（约 60 ms 检测一次）。隐藏时使用原生窗口隐藏，不阻挡下方软件的点击。
- 默认 Ctrl+Alt+L（Mac 为 ⌘+Alt+L）锁定 / 解锁。隐藏时也有效。锁定后，鼠标移入、打开设置或找回窗口都不会显示正文；只能通过已注册的锁定快捷键解锁。退出应用后重新启动会恢复未锁定状态。
- 鼠标移到阅读窗顶端显示工具栏，提供返回书架、目录、设置及关闭应用；拖动左侧点阵移动窗口。
- 拖动四边或四角缩放；设置也可输入宽高。最小 180×80，最大 3840×2160，设置保存时不超过当前屏幕工作区。
- 字号 10–48 px；背景不透明度 0–100%，仅背景变化，不影响文字透明度。支持文字与背景颜色、窗口置顶。
- 设置滑块可预览，点击“保存更改”才持久保存；关闭设置或找回阅读窗会恢复已保存的外观。
- 快捷键框可按组合录入，也可手动输入 `Control+Alt+L`、`Super+Alt+L`、`Control+Shift+F11` 等。冲突会提示，并保留原组合。已被其他程序占用的按键可能无法录入，可手动输入后保存检查。
- 全局上一页 / 下一页默认 Ctrl+Alt+Left / Right（Mac 为 ⌘+Alt+Left / Right），可自定义；正文可用滚轮或方向键翻页。
- 导入 5 MB 以内 TXT，自动尝试 UTF-8 / GB18030；自动识别章节、保存阅读进度并恢复最近阅读。旧版书架数据继续使用。
- 书籍存储在 Electron userData 的 IndexedDB，窗口配置在同目录 floating-preferences.json。清理应用数据前自行备份原 TXT；当前没有阅读进度导出。

## 开发与打包

在本项目目录（包含 `package.json`）中执行命令。依赖、打包产物、缓存和本地环境文件不会提交；源码、`package-lock.json`、`icons/` 和 `tests/` 需要保留。

```sh
npm ci
npm start
npm run check
npm test
```

Windows 免安装目录：`npm run pack`，运行 `release/win-unpacked/Quiet Reader.exe`，不要单独移动 EXE。

Windows 安装包：`npm run dist:win`。在 macOS 上执行 `npm run dist:mac` 生成 DMG；正式分发需要配置 Apple 签名与公证。Mac 的透明窗口、全局快捷键、多显示器与缩放需要在 Mac 实机验证。

## 验证边界

自动化测试覆盖悬停状态、锁定优先级、窗口缩放边界、快捷键冲突回滚及主进程 IPC 集成；系统 API 使用模拟对象，不能代替真实 Windows / Mac 的交互测试。
